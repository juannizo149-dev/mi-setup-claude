# Principios de animación
Toda animación necesita un **propósito**: orientar (de dónde viene algo), dar feedback, conectar estados o aportar personalidad.

Orden de decisiones:
1. ¿Debe animarse? → [[Cuándo no animar]]
2. ¿Qué propiedades? → [[Rendimiento de animaciones]]
3. ¿Qué curva? → [[Easing]] o [[Springs]]
4. ¿Cuánto dura? → [[Duración]]
5. ¿Varios elementos? → [[Coreografía y stagger]]
6. ¿Y con movimiento reducido? → [[Movimiento reducido]]

Herramienta: CSS para lo simple, [[GSAP]] para secuencias y scroll.
