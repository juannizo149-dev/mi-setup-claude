# Cuándo no animar
- Acciones con teclado o muy frecuentes (atajos, escribir).
- Datos que el usuario necesita leer ya.
- Decoración sin propósito.
- Cuando la animación retrasa la tarea.

Regla: si se repite cien veces al día, que sea instantáneo o casi.
