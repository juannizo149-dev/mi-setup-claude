# Coreografía y stagger
Coordinar varios elementos para que se lean como **un solo movimiento**.

- *Stagger*: retraso escalonado entre elementos, unos 30-60 ms cada uno.
- Limita el stagger total; con listas largas, anima solo los primeros.
- Mueve lo importante primero; el resto acompaña.

En GSAP: opción `stagger` de los [[Tweens]] y posiciones en [[Timelines]].

Relacionado: [[Principios de animación]], [[Duración]]
