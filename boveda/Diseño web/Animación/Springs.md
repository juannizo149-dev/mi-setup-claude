# Springs
Animaciones basadas en física (masa, rigidez, amortiguación) en lugar de una duración fija.

- Se sienten naturales e **interrumpibles**: si el usuario cambia de opinión a mitad, continúan desde donde están.
- Ideales para gestos: arrastrar, deslizar, hojas inferiores.
- Poco rebote en interfaces serias.

Relacionado: [[Easing]], [[Principios de animación]]
