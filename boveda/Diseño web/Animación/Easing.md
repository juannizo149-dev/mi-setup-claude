# Easing
Curva de velocidad de una animación.

- **ease-out**: para elementos que entran o responden al usuario. Es la opción por defecto.
- **ease-in-out**: para elementos que se desplazan de un sitio a otro en pantalla.
- **ease-in**: casi nunca; se siente lento al empezar.
- **linear**: solo para movimiento continuo (spinners, marquesinas).

Las curvas por defecto de CSS son flojas; prueba curvas personalizadas, p. ej. `cubic-bezier(0.23, 1, 0.32, 1)`.
