# Plugins de GSAP
- **SplitText**: anima letras, palabras o líneas por separado.
- **Flip**: anima cambios de layout (reordenar, mover entre contenedores).
- **Draggable** + **Inertia**: arrastrar con inercia.
- **MorphSVG**, **DrawSVG**: animación de SVG.
- **CustomEase**: crea tus propias curvas ([[Easing]]).

Siempre se registran: `gsap.registerPlugin(Flip, SplitText)`.

Relacionado: [[GSAP]], [[ScrollTrigger]]
