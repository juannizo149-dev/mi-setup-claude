# GSAP
Librería de animación en JavaScript; funciona con cualquier framework o sin él.

Piezas principales:
- [[Tweens]]: animar propiedades de A a B.
- [[Timelines]]: encadenar animaciones.
- [[ScrollTrigger]]: animar con el scroll.
- [[Plugins de GSAP]]: SplitText, Flip, Draggable...
- [[GSAP con React]]

Buenas prácticas: animar `x`, `y`, `scale`, `opacity` ([[Rendimiento de animaciones]]) y respetar el [[Movimiento reducido]].
