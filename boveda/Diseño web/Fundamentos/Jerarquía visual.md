# Jerarquía visual
Orden en que el ojo lee una pantalla. Se construye con tamaño, peso, [[Color]], contraste y [[Espaciado y layout|espacio]].

- Un solo elemento principal por pantalla.
- Menos estilos distintos = jerarquía más clara.
- La [[Tipografía]] es la herramienta más potente para crearla.

Relacionado: [[Sistema de diseño]], [[Alineación óptica]]
