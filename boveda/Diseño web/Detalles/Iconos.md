# Iconos
- Un solo set de iconos y un solo grosor de trazo.
- Tamaño acorde al texto que acompañan.
- Para cambiar de icono (p. ej. copiar → check), combina escala, opacidad y blur.
- Los iconos sin texto necesitan etiqueta ([[Accesibilidad]]).
