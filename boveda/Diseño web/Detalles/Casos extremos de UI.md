# Casos extremos de UI
Prueba cada componente con datos del peor caso:

- Nombres larguísimos o de una letra.
- Emails largos que no se pueden partir.
- Campos vacíos, cero elementos, miles de elementos.
- Texto en otros alfabetos y emojis.

CSS útil: `min-width: 0`, `overflow-wrap: anywhere`, `text-overflow: ellipsis`.
