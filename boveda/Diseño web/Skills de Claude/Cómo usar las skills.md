# Cómo usar las skills

- **Automático:** Claude lee la descripción de cada skill y la usa cuando encaja con lo que pides ("anima este botón" → [[Skills - Animación]]).
- **Manual:** escribe `/nombre-de-la-skill`, p. ej. `/impeccable audit` o `/graphify .`.

## Combinaciones útiles
- Diseñar una web: `frontend-design` + `impeccable` + `ui-ux-pro-max` → teoría en [[Mapa - Diseño web]].
- Animarla: `animate` + `gsap-*` + `transitions-dev` → [[Principios de animación]], [[GSAP]].
- Pulirla: `make-interfaces-feel-better` + `review-animations` + `break-ui` → [[Microinteracciones]], [[Casos extremos de UI]].
- Revisar seguridad: `differential-review` + `semgrep` → [[Skills - Seguridad y revisión de código]].
- Python: [[Skills - Python]].

## Consejos
- Demasiadas skills pueden solaparse; si una no se activa, llámala por su nombre.
- Pide "aplica las notas de mi bóveda" para que Claude use estas notas como referencia.
